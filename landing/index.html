Para quem é

Advogados

Pergunte sobre um processo como perguntaria a um estagiário e receba o andamento organizado, sem abrir portal por portal.

Escritórios

Acompanhe a carteira por número CNJ, gere resumos em linguagem simples para o cliente e estime prazos em dias úteis.

Departamentos jurídicos

Dê ao time interno uma consulta rápida ao contencioso da empresa usando a fonte oficial do CNJ, sem scraping.

Devs legaltech

Tools tipadas e prontas para agentes, em Python, via stdio. Plugue no seu produto em vez de reescrever cliente do DataJud.

O que você pergunta, o que ele faz

Perguntas reais de rotina e a tool que o assistente chama para responder.

  1. “Qual a situação do processo NNNNNNN-DD.AAAA.8.26.OOOO?”

    buscar_processo_por_numero

    Classe, assuntos, órgão julgador, datas e movimentações. Se você não disser o tribunal, ele é deduzido do próprio número CNJ.

  2. “Me mostre os últimos 10 andamentos.”

    listar_movimentacoes

    Histórico com nome do movimento, código TPU e data/hora, do mais recente para o mais antigo.

  3. “Resuma em linguagem simples para eu mandar ao cliente.”

    resumir_andamento

    Entrega os dados do processo ao assistente com instruções de resumo, para ele escrever o texto em português claro.

  4. “Teve novidade desde 1º de outubro?”

    monitorar_processo

    Diz se o processo teve atualização no DataJud depois da data informada e qual foi a data da última atualização.

  5. “Fui intimado hoje. Quando vence a contestação no TJSP?”

    calcular_proximo_prazo

    Conta em dias úteis (arts. 219, 220 e 224 do CPC), com recesso forense e feriados nacionais. Feriados estaduais entram quando a UF é informada. É uma estimativa de apoio: confira sempre.

Ferramentas

As 9 tools e o resource registrados em server.py.

Consulta e acompanhamento DataJud CNJ

buscar_processo_por_numero
Consulta completa pelo número CNJ (NNNNNNN-DD.AAAA.J.TR.OOOO).
listar_movimentacoes
Histórico de andamentos com código TPU e data/hora.
resumir_andamento
Dados do processo mais instrução de resumo para o modelo.
monitorar_processo
Verifica se houve atualização desde uma data.
listar_processos_monitorados
Lista os processos com snapshot gravado na sessão. Nesta versão, nenhuma tool de consulta grava snapshot, então a lista vem vazia.

Prazos e referência

calcular_proximo_prazo
Prazo em dias úteis com calendário forense. Roda offline quando você informa a data da intimação; sem ela, consulta o DataJud para usar a data da última movimentação. Feriados estaduais só entram com a UF informada.
listar_tribunais
As 92 siglas cadastradas no servidor e aceitas no parâmetro tribunal. Estar na lista não garante que o DataJud tenha dados daquele tribunal. Offline.

Domicílio Judicial Eletrônico opcional

listar_intimacoes
Comunicações recebidas no DJe. Somente leitura. Exige credenciais próprias do DJe.
confirmar_leitura_intimacao
Tem efeito jurídico real e inicia prazo. Roda em modo de simulação por padrão e só confirma com dupla autorização explícita.

Resource MCP

processo://{numero}/snapshot
Lê o snapshot gravado de um processo, se existir. Como buscar_processo_por_numero e monitorar_processo não gravam snapshot, nesta versão ele responde que não há snapshot disponível.

Instalação

Precisa do uv (ou de Python 3.10+ com pip). Não precisa de cadastro: por padrão o servidor usa a chave pública vigente divulgada pelo CNJ na wiki do DataJud. O CNJ pode trocar essa chave a qualquer momento; se isso acontecer, informe a nova em DATAJUD_API_KEY.

Teste no terminal

uvx mcp-juridico-brasil

Sem uv? Instale com curl -LsSf https://astral.sh/uv/install.sh | sh ou use pip install mcp-juridico-brasil.

Claude Desktop

Edite ~/Library/Application Support/Claude/claude_desktop_config.json (macOS) ou %APPDATA%\Claude\claude_desktop_config.json (Windows) e reinicie o app.

{
  "mcpServers": {
    "juridico-brasil": {
      "command": "uvx",
      "args": ["mcp-juridico-brasil"]
    }
  }
}
Cursor

Crie ou edite .cursor/mcp.json no projeto (ou ~/.cursor/mcp.json para todos os projetos).

{
  "mcpServers": {
    "juridico-brasil": {
      "command": "uvx",
      "args": ["mcp-juridico-brasil"]
    }
  }
}
Claude Code 
claude mcp add juridico-brasil -- uvx mcp-juridico-brasil
Outros clientes MCP

Qualquer cliente compatível com MCP via stdio funciona. Configure o comando uvx com o argumento mcp-juridico-brasil. Se instalou com pip, o comando é direto:

pip install mcp-juridico-brasil
mcp-juridico-brasil
Variáveis de ambiente (opcionais)

Defina no bloco "env" da configuração do cliente.

DATAJUD_API_KEY
Substitui a chave padrão quando necessário, por exemplo se o CNJ divulgar uma chave pública nova. Sem ela, o servidor usa a chave pública vigente que acompanha esta versão.
JURIDICO_SNAPSHOT_DIR
Pasta para persistir em disco snapshots gravados. Nesta versão as tools de consulta não gravam snapshot, então não há efeito prático no uso comum.
DJE_CLIENT_ID, DJE_CLIENT_SECRET, DJE_BEHALF_OF_CPF
Credenciais do Domicílio Judicial Eletrônico, só para as tools de intimação.

Perguntas frequentes

O que o DataJud cobre?

O DataJud é a base nacional de dados processuais mantida pelo CNJ. A API pública traz metadados do processo (número, classe, assuntos, órgão julgador, datas) e a lista de movimentações com códigos das Tabelas Processuais Unificadas. Os dados vêm do que cada tribunal envia ao CNJ.

Quais tribunais estão cobertos?

O servidor aceita 92 siglas de tribunais, que é o cadastro interno usado para montar a consulta. Estar cadastrado não garante que haja dados para aquele tribunal: segundo o CNJ, a base do DataJud abrange os tribunais dos incisos II a VII do art. 92 da Constituição, e o volume de dados de cada um depende do que ele envia. A lista inclui, por exemplo, o STF, que não está nesse recorte. Se uma consulta não retornar nada, confira no portal do tribunal.

O que o DataJud não cobre?

Não traz a íntegra de peças, petições, documentos ou o texto de decisões. Processos em segredo de justiça não são retornados pela API pública. A atualização depende do envio e do processamento dos dados pelos tribunais, então pode haver atraso em relação ao portal do tribunal, que continua sendo a fonte para decisões processuais.

O cálculo de prazo é confiável?

É uma estimativa técnica de apoio. Considera dias úteis, recesso forense (20/12 a 20/1) e feriados nacionais; feriados estaduais só entram quando você informa a UF. Se você não informar a data da intimação, o cálculo parte da data da última movimentação no DataJud, que pode estar desatualizada. Feriados municipais, pontos facultativos e suspensões extraordinárias não entram automaticamente. Confira sempre antes de protocolar.

Meus dados saem da minha máquina?

O servidor roda localmente e consulta direto a API do CNJ, que só devolve dados públicos. Não há servidor intermediário do projeto, e nesta versão as tools de consulta não gravam os resultados em disco. Lembre que o texto da conversa vai para o provedor do assistente de IA que você usa.

O monitoramento me avisa sozinho?

Não. O monitoramento é por consulta: o assistente verifica o que mudou quando você pede. Notificações automáticas estão no roadmap, não nesta versão.

Quanto custa?

Nada. O projeto é open source sob licença MIT e a API pública do DataJud é gratuita. O custo que existe é o do assistente de IA que você já usa.

Funciona com quais assistentes?

Com qualquer cliente que suporte o Model Context Protocol via stdio, como Claude Desktop, Claude Code e Cursor.

Isso substitui o advogado?

Não. As ferramentas organizam informação pública e não constituem consultoria jurídica. A análise e as decisões são do profissional habilitado.
